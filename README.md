# glance-template

Yam Custom template for Glance Dashboard

# Getting started

- Install Glance
- Install template

```bash
cd /opt/glance
rm glance.yml
git clone https://github.com/amkac/glance-template.git
```

- crate **prod.env** file, then configure token for your servcies.

```
PROXMOX=
PIHOLE=
```
